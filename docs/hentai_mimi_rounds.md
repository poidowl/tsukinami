# 変態耳（mimi）育てのラウンド記録

回すのは关亡婆、育てるのはナグリ。各ラウンドで、关亡婆（M6）に**調整用の台本だけ**の聞き間違いの要約
（`tools/mimi_soudan_matome.mjs`）を渡し、原因の順位と育て方の提案を JSON で書かせる（`tools/itako_soudan.py`）。
ナグリが筋のいい提案を実装し、下見（調整用の中の 4 台本を外して育てた表）で加減を選び、確認用（held-out、8 台本 51 行 × プリセット 6 × seed 3）で良くなったものだけ残す。
台帳（box の `obake_daichou.jsonl`）には 1 発話 1 行に加えて、ラウンドごとに `D_shurui: "ラウンド"` の行（提案・変更・前後の点）を足す。

点は「かな正答 / 母音正答」。r2 から正解は **kusanagi が実際に読んだモーラ列**（`--truth spoken`、例「ほう」→「ほー」→ ほお）。台本かなとの点（`kana_daihon`）も並べて出す。
