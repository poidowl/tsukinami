# カワイイクサナギ 変態音響解析ツール 100選 (`xray/`)

**純JS・外部依存ゼロ・合計約85KB** で、任意の音声（WAV）を **10カテゴリ × 10ツール = 100軸** で多角的に丸裸にする音響X線スイート（Node.js / ブラウザ ESM 両対応）。

## クイックスタート

```bash
# 登録されている全100ツール一覧を表示
node xray/run.mjs

# 複数WAVを100軸で一括比較（1本目が比較基準になる）
node xray/run.mjs voice_a.wav voice_b.wav

# JSON出力
node xray/run.mjs --json voice_a.wav voice_b.wav

# 全100ツール＋SVGビジュアルX線パネル入りHTMLレポートを一発生成
node xray/run.mjs --report report.html voice_a.wav voice_b.wav

# 自己検証テスト（合成正解信号＋V7.1音声で全100本の正常性＆物理感度を検証）
node xray/test_xray.mjs
```
